# Sample benchmark output

These small CSVs were generated while preparing this ZIP, in the build environment, for 8- and 20-session synthetic problems with one repetition. They are included to demonstrate the output format, not as performance claims about the student's computer or college data. Process-pool execution was slower in this small sample because process startup overhead outweighed any parallel benefit. Re-run the benchmark on the machine used for the defence with more repetitions and larger workloads; report those actual results.
